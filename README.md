# Consultancy System (Java)

## 📌 Description

This project is a simple Consultancy System developed using Java.
It demonstrates object-oriented programming concepts such as inheritance, method overriding, and the use of constructors.

The system models a basic consultancy environment where different types of users such as clients and consultants are represented using classes.

---

## ⚙️ Features

* Represents real-world entities (Client, Consultant, etc.)
* Uses inheritance to show relationships between classes
* Displays user information using methods
* Demonstrates method overriding
* Uses `this` and `super` keywords in constructors

---

## 🧠 Concepts Used

* Classes and Objects
* Inheritance (`extends`)
* Single and Multilevel Inheritance
* Method Overriding
* `this` Keyword
* `super` Keyword and constructor calls
* Access Modifiers (`protected`)
* Basic Java syntax and structure

---

## 🏗️ Project Structure

* **Person (Base Class)**
  Contains common attributes like name and age

* **Client (Subclass)**
  Represents a consultancy client and includes specific details

* **Consultant (Subclass)**
  Represents a consultant with specialization

* **(Optional) Advanced/Senior Consultant**
  Demonstrates multilevel inheritance

* **Main Class**
  Runs the program and displays output

---

## ▶️ How to Run

1. Save the file as:

   ```
   Main.java
   ```

2. Compile:

   ```
   javac Main.java
   ```

3. Run:

   ```
   java Main
   ```
